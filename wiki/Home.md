# TACZ Attributes Addon - Wiki

Welcome to the TACZ Attributes Addon wiki! This addon integrates TACZ (gun mod) with TACZ Attributes to add random attributes and a rarity system to guns.

## Full Configuration Guide

The complete configuration guide is also available as a single document in the repository's `docs/` directory. If you are not logged in to GitHub, the wiki may be rate-limited. In that case, please use these links instead:

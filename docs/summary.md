# Short Summaries (for platform submission forms)

## English

### One-liner (CurseForge/Modrinth summary field, ~150 chars)
Adds randomized attributes and rarity tiers (Common to Epic) to TACZ guns. Includes reroll stations, selective enhancement, 50+ configurable stats.

### Short Description (~300 chars)
Adds a randomized attribute and rarity system to all TACZ guns. Each gun rolls unique stats — damage, accuracy, recoil, fire rate, and more from 50+ attributes. Features Attribute Station (reroll), Enhancement Station (selective upgrades), 4 rarity tiers, per-gun presets, and full multiplayer support.

## 日本語

### ワンライナー（CurseForge/Modrinthの概要欄、約150文字）
TACZの銃にランダム属性とレアリティ（コモン〜エピック）を追加。属性リロールステーション、選択式強化、50種類以上の設定可能な属性を搭載。

### 短い説明（約300文字）
TACZの全銃にランダム属性とレアリティシステムを追加するアドオン。ダメージ・精度・リコイル・連射速度など50種以上の属性がランダムに付与されます。属性ステーション（リロール）、強化ステーション（選択強化）、4段階レアリティ、銃モデル別固定属性プリセット、フルコンフィグ対応。マルチプレイ完全対応。

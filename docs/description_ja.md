# TACZ Attributes Addon

**すべての銃をユニークなドロップに。** [TACZ](https://www.curseforge.com/minecraft/mc-mods/timeless-and-classics-zero)と[TACZ Attributes](https://www.curseforge.com/minecraft/mc-mods/tacz-attributes)を統合し、TACZの全銃にランダム属性・レアリティシステムを追加するアドオンMODです。拾った銃にはダメージ、精度、リコイル、連射速度など**50種類以上**のステータスがランダムに付与され、ハクスラ的なトレハン要素を楽しめます。

---

## 主な機能

### ランダム属性システム
入手したTACZ銃に自動で属性がランダム付与されます。ダメージ、精度、リコイル、操作速度、マガジン容量など**50種類以上**の属性プールから、銃タイプに適した属性が選ばれます。ショットガンにスナイパー専用属性が付くことはありません。

**4つの生成モード:**
- **Full Random** — 全属性から完全ランダム
- **Adaptive** — 銃タイプ・射撃モードでフィルタリング
- **Rarity Adaptive** *(デフォルト)* — フィルタ＋レアリティ重み付け＋分布スキュー
- **Balanced** — 上記すべて＋バフ/デバフ比率のバランス調整

### レアリティシステム
属性スコアの合計に基づいて銃にレアリティが付与されます:

| ティア | 色 | デフォルト閾値 |
|--------|-----|---------------|
| **コモン** | 白 | 50未満 |
| **アンコモン** | 黄 | 50以上 |
| **レア** | 水色 | 70以上 |
| **エピック** | 紫 | 100以上 |

レアリティはアイテム名の色に反映され、バニラのレアリティ表示と統合されます。

### 属性ステーション
銃の属性を**リロール（再抽選）**するためのクラフト可能なワークステーション。銃を入れて加工を待つと、新しいランダム属性が付与されます。
- 加工時間の設定可能
- 素材コスト（ダイヤモンドなど）のオン/オフ
- リロール回数の上限設定
- ホッパー対応（上/横から入力、下から出力）で自動化可能

### 強化ステーション
特定の属性を**選択的に強化**する上位ワークステーション。全リロールと異なり、**3つのランダムな強化選択肢**が提示され、好きなものを選んで適用できます。
- ランダムに提示される選択肢から好きな強化を選択
- 素材コストで選択肢のリロールが可能
- 銃ごとの強化回数上限を設定可能
- 強化を重ねるごとにコストが上昇（設定可能）
- ポジティブ効果のみに制限するオプション

### 銃モデル別の固定属性
JSONコンフィグで銃モデルごとに基本属性プリセットを定義できます。例：AK-47にダメージ微増＋リコイル増加を設定。固定属性はランダム属性と独立して両立し、両方が同時に適用されます。

### バラージュ（伝説級アイテム）
Vector .45を8個のエンチャントされた金リンゴで囲んでクラフトする特殊オフハンドアイテム。オフハンドに持つと:
- **連射速度 +100%**（RPM2倍）
- **抜刀速度 +50%**
- **ADS速度 +50%**

耐火性、エピックレアリティ、エンチャントの輝き付き。

### 詳細なツールチップ
**Shift**を押しながら銃にカーソルを合わせると詳細情報が表示されます:
- レアリティティアとスコア
- ランダム属性（金色テキスト）
- 固定属性（青色テキスト）
- 強化属性（紫色テキスト）
- リロール回数・強化回数
- バフ（緑）/デバフ（赤）のカラー表示

### 管理者コマンド
サーバー管理者は以下のコマンドで完全制御可能:

| コマンド | 説明 |
|----------|------|
| `/taczaddon clear` | 手持ち銃のアドオン属性を全削除 |
| `/taczaddon clear random/fixed` | 特定種類の属性のみ削除 |
| `/taczaddon reroll` | ランダム属性をリロール |
| `/taczaddon reload` | JSONコンフィグをホットリロード |
| `/taczaddon info` | 属性データの詳細表示 |
| `/taczaddon config get/set` | 設定値の取得・一時変更 |

## コンフィグ

全設定は `config/tacz_attributes_addon-common.toml` で変更可能:

- **機能トグル** — ランダム属性、固定属性、ステーション、レアリティスコアの有効/無効
- **生成モード** — 4つのランダム化アルゴリズムから選択
- **属性数** — 銃あたりの最小/最大属性数（デフォルト: 1〜5）
- **値の分布** — 線形、指数関数、二次関数カーブ
- **レアリティ閾値** — 各ティアのスコア境界をカスタマイズ
- **ステーション設定** — 加工時間、素材コスト、リロール上限
- **強化設定** — 選択肢数、最大強化回数、コストスケーリング

### 外部JSONコンフィグ
- `config/tacz_attributes_addon/attribute_pool.json` — 属性プール（重み、範囲、レアリティティア）
- `config/tacz_attributes_addon/weapon_attributes.json` — 銃モデル別の固定属性定義

どちらも `/taczaddon reload` でホットリロード可能。

## 前提MOD

- **Minecraft** 1.20.1
- **Forge** 47+
- **TACZ** (Timeless and Classics Zero) — 必須
- **TACZ Attributes** — 必須
- **Apotheosis** — 任意（ソケット連携）

---

## マルチプレイ対応

完全マルチプレイ対応。属性データはアイテムNBTに保存され自動同期されます。プレイヤーごとに独立した属性追跡でコンフリクトの心配はありません。

## 概要（短い説明文）

> TACZの銃にランダム属性とレアリティシステムを追加するアドオンMOD。ダメージ・精度・リコイル・連射速度など50種類以上の属性がランダムに付与されます。属性ステーション（リロール）、強化ステーション（選択強化）、4段階レアリティ、銃モデル別プリセット、全設定カスタマイズ可能。マルチプレイ完全対応。
